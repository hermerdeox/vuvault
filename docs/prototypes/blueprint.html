§ 01 — Design principles

Five non-negotiable invariants.

Every layer is checked against these five before it ships. If a feature breaks one, it does not ship — even if a competitor offers it, even if it's convenient.

P1
Server cannot read user data.
Mathematical, not policy. The wire only carries opaque ciphertext.
P2
Server cannot infer user data.
No metadata leaks: not which item changed, not how many items exist.
P3
Resistant to harvest-now-decrypt-later.
Hybrid post-quantum encryption from day one. FIPS 203.
P4
Verifiable by anyone.
Reproducible builds, transparency log, open source. No trust required.
P5
No silent updates.
Bundle hash visible at unlock. SRI on every asset. User-consented updates only.
§ 02 — Stack ordering by shippability

Ship now → ship 2030.

Eighteen layers organized by research risk, not architectural elegance. Tier 1 contains everything VuVault can ship today using only published RFCs and audited libraries. Tier 4 contains primitives whose academic results were published in 2024 or 2025 and are not yet ready for production but are likely to mature into shippable engineering by 2030. Each tier is a coherent deliverable.

Crypto
Encryption · core
Hybrid PQ vault envelope
Vault file encrypted under hybrid ML-KEM-1024 + X25519 KEM with AES-256-GCM. Resistant to harvest-now-decrypt-later: a vault exfiltrated today remains undecryptable in 2032+. 10
PIR
Privacy-preserving queries
PIR + unbalanced PSI breach checks
Hybrid: single-server PIR with VOPRF for low-overhead checks, unbalanced PSI with downloadable hint for high-assurance. Server learns zero — not the password, not a hash, not even a 5-character prefix. Replaces the leaky k-anonymity-over-SHA-1 pattern that every incumbent ships. Recent unbalanced PSI yields ~4s for 2³² password set with reusable 240MB hint.

FROST t-of-n device recovery

§ 03 — Shipping milestones

Each tier is a deliverable.

Every milestone is shippable on its own. v1.0 already exceeds every incumbent on the four hardest claims. v2.0 makes VuVault the only credential manager with verifiable transparency. v3.0 closes the agentic-AI gap. v4.0 is a research bet — but framed as a research bet, not a roadmap commitment.
