📦 What is a Master File?

A Master File (.vu) is a complete, encrypted backup of your entire VuVault vault including:

  • ✅ All passwords and credentials
  • ✅ Application settings and preferences
  • ✅ Custom folders and tags
  • ✅ Security configurations
  • ✅ Device fingerprints and metadata
  • ✅ Quick access favorites
Example filename: A3X9K_141225.vu
Format: {5 random chars}_{DDMMYY}.vu
Size: Typically 10-100 KB (compressed & encrypted)

🔒 Security Features

  • ChaCha20-Poly1305 authenticated encryption Military Grade
  • PBKDF2-SHA512 key derivation (210,000 iterations)
  • Password Protected - You set the password during export
  • SHA-256 Checksum - Integrity verification
  • Zero-Knowledge - All encryption happens locally
  • Unique Salts - Different encryption each export
⚠️ Important: Store your .vu file password securely. Without it, the backup cannot be restored. The password is NOT stored anywhere in the file.

📤 How to Export a Master File

  1. Navigate to Settings in VuVault Zero
  2. Find the MASTER BACKUP section
  3. Click CREATE MASTER BACKUP
  4. Enter a strong password (minimum 8 characters)
  5. Confirm the password
  6. Click EXPORT MASTER FILE
  7. File downloads as XXXXX_DDMMYY.vu
✅ Your master file contains EVERYTHING - a complete snapshot of your vault at that moment.

📥 How to Import a Master File

  1. Navigate to Settings in VuVault Zero
  2. Find the MASTER BACKUP section
  3. Click RESTORE FROM BACKUP
  4. Drag & drop your .vu file or click to browse
  5. Enter the password you used during export
  6. Click IMPORT MASTER FILE
  7. Review import results

Import behavior:

  • ✅ Existing items are preserved
  • ✅ Duplicate items are skipped
  • ✅ Settings are merged intelligently
  • ✅ New items are added to your vault

💡 Use Cases

  • Complete Backup: Before major changes or updates
  • Device Migration: Move your vault to a new device
  • Disaster Recovery: Restore after data loss
  • Archive Snapshots: Keep dated backups of your vault
  • Secure Sharing: Share vault with trusted parties (with password)
  • Offline Storage: Store on USB/external drives

🎯 Best Practices

  • 📅 Create regular backups (weekly/monthly)
  • 🔑 Use unique, strong passwords for each backup
  • 💾 Store backups in multiple secure locations
  • 📝 Keep a record of backup dates and passwords (separately)
  • 🧪 Test restore process periodically
  • 🗑️ Delete old backups you no longer need
  • 🔒 Encrypt backup storage locations

⚡ Quick Facts

  • File extension: .vu (VuVault)
  • Encryption: ChaCha20-Poly1305
  • Key derivation: PBKDF2-SHA512 (210,000 iterations)
  • Format: Base64 encoded JSON container
  • Compatibility: VuVault Zero v2.0.0+
  • Processing: 100% client-side (no server)
