📥 Import Functionality

VuVault Zero supports importing from:

  • ✅ JSON Files - 1Password, Bitwarden, LastPass, Dashlane, KeePass, and more
  • ✅ CSV Files - Generic CSV and AWS Credentials format
  • ✅ 11+ Password Managers - Automatic format detection

How to Import Your CSV

  1. Go to VuVault Zero at http://localhost:3005
  2. Navigate to Settings (gear icon in top right)
  3. Click IMPORT in the Data Management section
  4. Drag and drop your credentials.csv file or click to browse
  5. Review the preview and click IMPORT

📤 Export Functionality

VuVault Zero supports exporting in two formats:

JSON Export

  • Full vault backup with all metadata
  • Encrypted passwords included
  • Can be re-imported to VuVault
  • Preserves tags, notes, and timestamps
{
  "version": "2.0.0",
  "exported": "2025-09-14T...",
  "format": "vuvault",
  "items": [...]
}

CSV Export

  • Universal format for spreadsheets
  • Compatible with Excel, Google Sheets
  • Easy to migrate to other password managers
  • Human-readable format
Service,Username,Password,URL,Notes,Tags,Created,Updated
AWS Console,BU3C81ZSP0N4O574A4FH,****,https://console.aws.amazon.com/,...

How to Export

  1. Go to Settings
  2. In Data Management section, find "Export Vault"
  3. Choose format:
    • EXPORT JSON - For backup and re-import
    • EXPORT CSV - For spreadsheets or migration
  4. File will download automatically

🔒 Security Notes

⚠️ Important Security Information:

  • Exported files contain your actual passwords (encrypted in JSON, plain in CSV)
  • Store exports securely and delete after use
  • CSV exports are unencrypted - use only for migration
  • JSON exports maintain encryption but should still be protected
  • All import/export operations happen locally in your browser
  • No data is sent to any server
