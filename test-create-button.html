🔍 Troubleshooting

If the button still doesn't work:

  1. Open Developer Console (F12)
  2. Look for error messages when clicking CREATE
  3. Check for these common issues:
    • • "No master key available" → Import something first or clear data
    • • "Failed to save password" → Database issue, try clearing data
    • • No console output → Button click not registering
